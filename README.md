# Identifying Modern Ball-Playing Centre-Backs

This project applies a multivariate statistical scouting framework to identify, profile, and evaluate modern centre-backs. Moving beyond basic descriptive statistics, this engine applies dimensionality reduction, possession-adjusted metrics, and cosine similarity algorithms to establish robust tactical archetypes and identify high-value market inefficiencies.

The pipeline processes event data to build composite tactical indicators, flagging profiles that fit a high-possession, proactive game model.

---

# Methodology

## 1. Data Filtering & Aggregation

Players were filtered to ensure positional accuracy, statistical significance, and relevance:

* Primary position: Central Defender (DF).
* Minimum threshold of 900 minutes played.
* Aggregation of the last four seasons to establish a stable, longitudinal performance profile, mitigating variance from small sample sizes.

## 2. Feature Engineering & Contextual Metrics

Several advanced tactical indicators per 90 minutes were constructed from raw event data to reflect the modern demands of the position:

* **Expected Threat (xT) Proxy:** A heuristic model quantifying the territorial and offensive value generated by a defender's passing and carrying decisions.
* **Possession-Adjusted Defending (PAdj):** Defensive metrics (tackles and interceptions) were adjusted based on opponent possession volume (100 - team possession). This eliminates the inherent bias of counting stats, where defenders in low-possession teams artificially accumulate more actions.
* **Ball Progression:** A weighted combination of progressive passes and progressive carries.
* **Passing Security:** Overall pass completion efficiency, acting as the baseline for build-up reliability.
* **Composite Scouting Score:** An aggregated metric balancing progression, defensive output, passing security, and an age modifier to highlight recruitment value.

## 3. Standardisation

All engineered variables were standardised using z-score scaling prior to any multivariate analysis. This ensures equal weighting across different statistical scales (e.g., passing percentages vs. absolute defensive actions).

## 4. K-Means Clustering & PCA Projection

Players were segmented into distinct tactical roles based on their multivariate profile. The optimal number of clusters (k=4) was strictly validated and selected based on Within-Cluster Sum of Square (WSS) and silhouette analysis optimisation.

Principal Component Analysis (PCA) was subsequently used to project these multidimensional profiles into a 2D visual space, facilitating the interpretation of latent tactical structures.

## 5. Player Similarity Engine

A non-parametric recommendation system was built using Cosine Similarity. By evaluating the standardised metrics in a multidimensional space, the engine identifies statistical "clones" of elite targets, providing objective, data-driven alternatives for recruitment and succession planning.

---

# Key Findings

The integration of contextual metrics yielded significant tactical insights:

1. **The PAdj Reality:** Adjusting for possession drastically alters the defensive landscape. Defenders in dominant teams (who face fewer defensive transitions) are properly evaluated, highlighting profiles that maintain elite defensive intensity per opportunity rather than sheer volume.
2. **Tactical Archetypes:** The clustering algorithm identified four distinct roles, ranging from elite progressive distributors (high xT and ball progression) to conservative defensive stoppers (high PAdj metrics, lower passing security).
3. **Market Inefficiencies:** By plotting the composite scouting score against player age, the framework successfully isolates U-24 defenders overperforming their expected tactical output, highlighting high-potential targets before they reach peak market valuation.
4. **Viable Succession Planning:** The similarity engine proved capable of finding exact statistical matches (often exceeding 94% similarity) for elite profiles, allowing for highly targeted recruitment filtering.
